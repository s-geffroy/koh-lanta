{%- comment -%} Le rail de navigation. Sur grand ecran il est deplie en permanence ; sur petit ecran, c'est un vrai
qui se replie -- aucun JavaScript n'intervient, la commande est celle du navigateur. L'entree courante est reconnue en comparant `page.url` a l'`url` declaree dans _data/navigation.yml. C'est pour cela que les deux doivent s'ecrire a l'identique, barre oblique finale comprise. Une entree peut porter `badge:`, un chemin pointe dans site.data.stats (« completude_saisons.moyenne »). Le rail affiche alors la valeur a cote du titre. Elle est donc toujours a jour : c'est le fichier de statistiques qui la donne, jamais un chiffre recopie a la main dans la navigation. {%- endcomment -%}
